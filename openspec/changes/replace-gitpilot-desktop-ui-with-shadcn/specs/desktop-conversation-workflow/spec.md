## ADDED Requirements

### Requirement: 新 UI 保持消息和执行批次语义
系统 SHALL 按现有 store 规则展示用户消息、助手正文、执行摘要和错误，不得把原始工具输出重新混入对话正文。

#### Scenario: 工具回合后输出正文
- **WHEN** Agent 完成一批工具调用并随后输出助手正文
- **THEN** 对话先显示一个可展开的工具批次摘要，再显示新的助手正文消息

#### Scenario: 连续无正文工具回合
- **WHEN** Agent 连续完成多个没有助手正文分隔的工具回合
- **THEN** UI 将这些工具步骤合并到同一批次摘要中

### Requirement: 对话滚动尊重用户位置
系统 SHALL 在新会话或历史会话首次布局时直接定位到底部，并在流式输出期间仅当用户仍接近底部时自动跟随。

#### Scenario: 打开历史会话
- **WHEN** 用户切换到包含历史消息的会话
- **THEN** 首帧直接显示会话底部，不出现从顶部平滑滚动到底部的过程

#### Scenario: 用户阅读旧内容
- **WHEN** 用户在流式输出时手动滚动并离开底部阈值
- **THEN** 新消息不会强制把视口拉回底部

### Requirement: 输入器保留完整 Agent 操作
系统 SHALL 保留发送、停止、附件拖放、模型选择、思考级别、slash 命令和预填重试能力，并使用新组件系统统一呈现。

#### Scenario: 流式中停止
- **WHEN** Agent 正在执行且用户点击输入器停止按钮或触发对应快捷键
- **THEN** UI 调用现有 abort action，并保持已接收内容可见

#### Scenario: 拖放附件
- **WHEN** 用户把受支持文件拖到输入器
- **THEN** 命中区只覆盖输入器交互表面，附件进入现有准备流程且聊天滚动条仍可点击

### Requirement: 命令和模型选择支持键盘操作
系统 SHALL 使用可搜索的 Command 类组件呈现全局命令、模型和 slash 命令，并保持现有快捷键和思考级别提交值。

#### Scenario: 打开模型选择
- **WHEN** 用户按 Ctrl/Cmd+L
- **THEN** 模型选择器获得焦点并允许搜索、方向键选择和 Enter 确认

#### Scenario: 二档思考模式
- **WHEN** 当前模型只暴露 off 和一个启用档位
- **THEN** UI 显示 off/on，但向现有 action 提交真实档位值

### Requirement: 会话时间轴保持用户提问导航
系统 SHALL 继续只使用用户提问构建会话时间轴，并在长会话中保留首尾提问和均匀抽样。

#### Scenario: 长会话导航
- **WHEN** 会话中的用户提问数量超过时间轴最大条目数
- **THEN** 时间轴保留首条、末条和中间均匀抽样条目，点击后定位到对应消息
