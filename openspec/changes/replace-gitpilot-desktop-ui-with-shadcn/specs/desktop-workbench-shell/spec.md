## ADDED Requirements

### Requirement: 工作台保留完整功能分区
系统 SHALL 提供自定义标题栏、项目任务左栏、对话中心区、执行右栏、输出/终端底栏和状态栏，并保持现有业务入口可达。

#### Scenario: 标准窗口显示
- **WHEN** 应用以 1100x720 或更大窗口打开
- **THEN** 用户可同时访问项目任务导航、对话、执行检查器和状态栏，底栏可按需展开

#### Scenario: 最小窗口显示
- **WHEN** 应用以 800x500 最小窗口打开
- **THEN** 中心对话保持可用，右栏折叠为可打开面板，左栏可以折叠且不会使主要操作不可达

### Requirement: 面板尺寸和折叠状态保持兼容
系统 SHALL 继续使用现有工作台布局状态保存左栏宽度、右栏宽度、底栏开关和左右折叠状态。

#### Scenario: 重启恢复布局
- **WHEN** 用户调整面板尺寸或折叠状态后重新启动应用
- **THEN** 新 UI 根据现有持久化数据恢复有效布局，并对超出新边界的值进行安全夹取

### Requirement: 平台连接和本地运行状态分别展示
系统 SHALL 将平台后端连接、sidecar 生命周期和 Agent 执行状态作为不同语义展示，不得将 sidecar ready 等同于平台已连接。

#### Scenario: 后端停止但 sidecar 正常
- **WHEN** 本地 sidecar 可用但平台健康探测失败
- **THEN** UI 显示本地 Agent 可用，同时将平台连接标记为未连接

### Requirement: 底部终端保持独立原生桥接
系统 SHALL 在新工作台底栏中继续承载现有 Windows PowerShell 终端组件，不得把终端输入输出接入 Agent sidecar 消息流。

#### Scenario: 打开终端
- **WHEN** 用户从状态栏打开终端
- **THEN** 底栏切换到终端视图并使用当前项目目录启动或显示终端，Agent 会话状态不受影响
