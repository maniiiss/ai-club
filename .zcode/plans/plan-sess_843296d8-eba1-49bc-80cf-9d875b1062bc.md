# GitPilot CLI 汉化 + 移除 PI agent 更新日志 实现方案

## 目标与决策（已与用户确认）
1. **终端可见 UI 全部汉化**：banner、--help、子命令帮助、状态/错误/警告、各选择器组件、斜杠命令描述、登录引导、llama 扩展 UI 等。`src/core/messages.ts` 进入 LLM 上下文的文案（compaction summary 前缀、bash 输出标记等）**保持英文**，避免影响模型行为与上游兼容。
2. **更新日志彻底移除**：删启动 What's New 横幅 + `/changelog` 命令 + changelog 解析器 + 相关 settings 字段 + 根目录 `CHANGELOG.md`。
3. **Earendil 上游公告彩蛋一并移除**：`/dementedelves` 派发 + 组件 + 配图。
4. **不引入 i18n 层**，直接替换字符串字面量（与现有 `src/extensions/gitpilot/` 中文风格一致）。
