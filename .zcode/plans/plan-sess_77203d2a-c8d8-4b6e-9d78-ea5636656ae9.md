## Phase 4：GitPilot CLI 代理埋点（Java，新增——本期纳入 CLI 调用）

**改 `AgentType.java`**：新增 `GITPILOT_CLI("GitPilot CLI 本地推理")`

**改 `GitPilotModelProxyService.java`**（`:44` stream）：
- 注入 `AgentInvocationRecorder` + 复用 `ModelConfigService`（解析 provider/modelName）
- 从 `requireModelSession` 拿 `ModelSessionState`（userId, modelConfigId，`GitPilotCliService.java:270`）+ `resolveModelConfig` 拿 provider/modelName
- 转发前 `recorder.startManual(ctx)`：`GITPILOT_CLI`/provider/modelName/modelConfigId/userId/`TriggerSource.USER_DIRECT`
- **核心改造**：把 `input.transferTo(out)`（`:90`）改为**分块透传 + 嗅探 SSE usage**（只读不改字节，保持流式忠实）：
  - OpenAI Chat Completions：末 chunk `usage.{prompt,completion,total}_tokens`
  - Anthropic：`message_start` 的 `usage.input_tokens` + `message_delta` 的 `usage.output_tokens`（total 求和）
- 拿到 usage 后 `sink.setUsage(...)`；成功 `commit()`，异常 `fail(ex)`，客户端断开 `finish(CLIENT_DISCONNECTED)`
- **风险**：嗅探不得修改/缓存整个流（避免破坏流式体验与 provider 格式兼容），仅旁路解析 `data:` 行

**Harness**：`cd backend && mvn -s maven-settings-central.xml test`（测代理落账：mock 上游 SSE 含 usage，验证 `agent_invocation_log` 写入 `GITPILOT_CLI` 且 token 非空；测客户端断开落 `CLIENT_DISCONNECTED`）
