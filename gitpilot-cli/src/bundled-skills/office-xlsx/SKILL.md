# Excel / XLSX

使用 `office_create_document` 生成真实 `.xlsx`，并用 `office_inspect_document` 复核工作表内容。不要用 CSV、Markdown 表格或 JSON 冒充 Excel 文件。

## 数据优先

1. 先说明数据来源、统计口径、主键、时间范围和空值/重复值处理方式；没有依据时不补造数据。
2. 涉及汇总、预算和分析时，先让用户确认指标定义和工作表结构。输出应保留原始数据、处理结果和说明，而不是只交付结论。
3. 将每个工作表的名称、行、单元格值和公式作为结构化输入传给工具。公式可以带或不带 `=`，但必须引用实际存在的单元格。
4. 生成后检查关键表、公式文本和总计是否存在；如有对账要求，必须报告是否对平，不能静默忽略差异。

## 修订规则

- 默认新建带版本号的工作簿，避免覆盖用户手工录入的内容；覆盖已有文件必须由用户明确确认。
- 不把无法确认的金额、负责人或日期写成事实。可用空值、`待确认` 或单独工作表表达缺口。
- 交付时说明文件路径、各 Sheet 用途、公式/口径以及仍需人工核验的内容。
