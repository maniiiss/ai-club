# Word / DOCX

使用 `office_create_document` 生成真实 `.docx`，不要把 Markdown、HTML 或纯文本改名为 `.docx`。生成后使用 `office_inspect_document` 做一次内容检查。

## 生成流程

1. 先读取用户给出的材料，分清事实来源、参考材料和待确认项；不能从材料确认的数字、日期、责任人或结论必须标为待确认。
2. 对结构、受众或审批用途不明确的正式文档，先给出标题层级和关键表格字段，等用户确认后再生成文件。
3. 调用工具时，将标题、章节标题、段落和可选表格传入结构化字段；输出路径必须位于当前 Work 工作区，使用 `.docx` 后缀。
4. 生成后检查标题、关键段落和表格文字是否可抽取；检查失败时说明原因，不要声称文件可用。

## 修订规则

- 小改动先明确变更点；不能基于猜测重写整份正式文档。
- 当前生成工具以新建文档为主。需要大范围改版时输出带版本号的新文件，例如 `output/project-plan-v2.docx`；仅在用户明确确认覆盖时才传入覆盖选项。
- 交付时说明文件路径、信息来源、待确认项和本次改动；不要把审阅、签发或法律结论当成已经完成。
