# PowerPoint / PPTX

使用 `office_create_document` 生成真实 `.pptx`，再用 `office_inspect_document` 检查各页文本。不要把图片、PDF 或 Markdown 改名为 `.pptx`。

## 先做故事线

1. 先确认受众、汇报时长、决策目标、页数上限、必须保留的材料和数据来源。
2. 先给出逐页标题与核心观点；对管理汇报，每页只表达一个主要结论。故事线未经确认时，不直接生成整份演示稿。
3. 调用工具时按页面传入标题和要点，输出路径必须位于当前 Work 工作区并使用 `.pptx` 后缀。
4. 生成后检查每一页是否有可抽取的标题/正文；无法确认的事实或数据要显式标注为待确认，不能用“行业数据”补齐。

## 交付与迭代

- 当前生成工具交付基础可编辑版式。需要更换主题、复杂图表、动画或逐元素精修时，说明限制并建议在 WPS/PowerPoint 中继续编辑。
- 重大修改默认创建 `-v2.pptx` 等新版本；只有用户明确要求覆盖时才覆盖旧文件。
- 交付时说明文件路径、页数、素材来源和仍需人工审核的页面。
